# 한국어 어휘력 측정 퀴즈 앱 (Korean Vocabulary Quiz App)

국립국어원 한국어기초사전 데이터(약 5만 단어)를 활용하여, 자신의 한국어 어휘력을 4지선다 퀴즈 형식으로 측정하고 관리할 수 있는 웹 애플리케이션입니다.

## 📌 주요 기능

*   **맞춤형 4지선다 퀴즈**: 랜덤으로 출제되는 단어의 올바른 뜻을 맞히는 퀴즈입니다. 오답 선택지는 FastText 벡터 기반으로 계산된 '의미적으로 유사한 단어'의 뜻풀이로 구성되어 난이도가 높고 학습 효과가 좋습니다.
*   **상세한 학습 통계**: 
    *   품사별 (명사, 동사, 형용사)
    *   난이도별 (초급, 중급, 고급)
    *   어종별 (고유어, 한자어, 외래어, 혼종어)
    *   주제/상황별 정답률 및 기출률(진행도)을 시각적인 프로그레스 바와 함께 제공합니다.
*   **검색 및 데이터 관리**: 전체 단어 목록을 검색하고 필터링(난이도/품사/정답 상태)할 수 있으며, 개별 단어나 전체 학습 기록을 리셋할 수 있습니다.
*   **세련된 UI/UX**: Apple Human Interface Guidelines(HIG)를 준수하여 설계되었으며, 시스템 테마(라이트/다크 모드)를 자동 지원합니다.

## 📂 프로젝트 구조

```text
korean-words-understanding/
├── index.html           # 메인 애플리케이션 HTML
├── index.css            # Apple HIG 준수 스타일시트 (다크모드 지원)
├── app.js               # 핵심 퀴즈 로직 및 상태 관리 (Vanilla JS)
├── data/                
│   ├── words.json          # 전처리 완료된 단어 사전 데이터
│   └── similarity_map.json # FastText 기반 유사어 매핑 데이터
└── scripts/             # 데이터 전처리 파이프라인
    ├── preprocess.py       # 원본 JSON 필터링 및 어종 분류
    └── build_similarity.py # 단어 간 유사도 계산 스크립트
```

## 🚀 실행 방법

본 앱은 클라이언트 사이드 바닐라 자바스크립트로 작성되어 있어, 로컬 웹 서버를 띄우기만 하면 바로 실행할 수 있습니다. (CORS 문제 방지를 위해 로컬 서버 실행을 권장합니다.)

**Python을 사용하는 경우:**
```bash
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

**Node.js를 사용하는 경우:**
```bash
npx serve .
# 이후 브라우저에서 표시되는 로컬 주소(예: http://localhost:3000)로 접속
```

## 🛠 데이터 전처리 파이프라인 (참고용)

이미 `data/` 디렉터리에 처리된 JSON 파일이 포함되어 있으므로 즉시 실행 가능합니다. 만약 원본 데이터를 다시 처리하거나 유사어 맵을 새로 구축하려면 다음 스크립트를 사용합니다.

1. **사전 전처리**:
   `scripts/preprocess.py`를 실행하여 원본 국립국어원 JSON(1216884/ 폴더 내)에서 명사, 동사, 형용사만 추출하고 어종을 분류하여 `words.json`을 생성합니다.
2. **유사어 매핑 생성**:
   `scripts/build_similarity.py`를 실행하여 FastText `cc.ko.300.vec` 모델을 기반으로 단어 간 유사도를 계산하고 `similarity_map.json`을 생성합니다. (※ 실행을 위해서는 수 GB의 FastText 모델 파일과 gensim 라이브러리가 필요합니다.)

## 📝 학습 기록 저장

사용자의 퀴즈 풀이 결과(정답/오답/모름 상태)는 브라우저의 `localStorage`에 영구 저장됩니다. 앱을 닫았다가 다시 열어도 이전 학습 기록이 그대로 유지되며, 이미 정답을 맞힌 단어는 다시 출제되지 않습니다. (설정에서 언제든지 리셋 가능합니다.)
